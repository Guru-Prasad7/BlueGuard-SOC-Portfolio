🔍 OpenVAS Scan Results

I ran OpenVAS against the full /24 and it found 30 vulnerabilities. At first I was overwhelmed by the report — OpenVAS spits out a LOT of noise. I had to manually verify each finding to separate real issues from false positives. Here's what actually mattered:

🛡️ My Remediation Plan

Priority 1 — Critical (0-48 hours)

  • Upgrade Log4j to version 2.17.1+ or apply vendor patches — this should have been done ages ago
  • Set strong MySQL root password and bind to localhost only — basic hardening that was skipped
  • Disable SMBv1 via PowerShell: Set-SmbServerConfiguration -EnableSMB1Protocol $false — one command, zero reason not to

Priority 2 — High (48 hours - 2 weeks)

  • Update Apache to 2.4.57 and configure security headers — HSTS, X-Frame-Options, CSP
  • Disable TLS 1.0/1.1, enable TLS 1.3 only — test legacy apps first though
  • Apply Windows security patches (KB501...) to all servers — patch Tuesday exists for a reason
  • Replace SNMP default community strings with complex values — "public" and "private" should be banned

📝 What I Learned From This Assessment

This was my first full vulnerability assessment and I made a ton of mistakes. I initially ran Nmap without -sV and missed service versions. I didn't save my first OpenVAS scan and had to re-run it (took 3 hours). I also learned that CVSS scores don't tell the whole story — context matters. A medium vulnerability on a domain controller might be worse than a high on an isolated test box. I'm still learning how to prioritize properly, but this exercise gave me a solid foundation.
