## 🚀 Quick Start Guide

### Step 1: Personalize
Replace all `[Your Name]` placeholders with your actual name.

### Step 2: Add Certificates
- Scan/take screenshots of your BTL1 and Cisco certificates
- Save them in `07-Certifications/` folder
- Update `07-Certifications/README.md` with your details

### Step 3: Add Visuals
- Create network topology diagrams (use Draw.io / Lucidchart)
- Take screenshots of tools (Splunk, Wireshark, Any.Run)
- Save in `assets/diagrams/` and `assets/screenshots/`

### Step 4: Upload to GitHub
```bash
git init
git add .
git commit -m "Initial portfolio upload"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/BlueGuard-SOC-Portfolio.git
git push -u origin main
```

### Step 5: Update LinkedIn
Add to Featured section: "BlueGuard SOC Portfolio - GitHub"
