Phishing Incident Response Report

IR-2026-001 | SOC Analyst: Guruprasad S | Classification: INTERNAL USE ONLY

📋 Incident Overview

Incident Type: Spearphishing with Malicious Attachment
Detection Date: August 12, 2026
Severity: HIGH
Status: RESOLVED
Impact: 3 user accounts compromised, 1 endpoint infected with Cobalt Strike beacon

🔍 Initial Detection

The incident was detected through multiple correlated alerts:

  • Email security gateway flagged suspicious attachment (Q3_Financial_Report.docm)
  • EDR triggered on PowerShell execution with encoded command
  • SIEM correlation rule fired: "Suspicious PowerShell + Outbound Connection"
  • Network monitoring detected beaconing pattern to 185.220.101.47:443

🎯 Containment Actions

Immediate Containment (T+15 minutes)

  • Isolated infected workstation (WS-FIN-04) from network
  • Blocked C2 IP 185.220.101.47 and domain at firewall
  • Disabled affected user accounts in Active Directory
  • Forced password reset for all Finance department users

Eradication (T+2 hours)

  • Removed Cobalt Strike beacon and persistence mechanisms
  • Cleaned Registry Run keys and scheduled tasks
  • Reimaged affected workstation with clean golden image
  • Revoked all active sessions for compromised accounts
